# 翻牌配對

教學用的翻牌配對小遊戲。老師自訂配對內容與圖片，學生用滑鼠或平板觸控來玩。
純前端網頁，不需要伺服器、帳號或網路；題庫與圖片只存在使用者自己的瀏覽器裡。

## 開始使用

**最簡單的方式：單機版。** 執行 `node scripts/build-standalone.js` 會在 `dist/` 產生單一檔案 `翻牌配對.html`，把它複製給別人，雙擊用瀏覽器開就能玩，不需要伺服器或網路（詳見下方「單機版」）。

另外兩種方式：

原始碼由多個檔案組成，**不能直接雙擊 `index.html` 開啟**（瀏覽器在 `file://` 下會擋掉模組載入），需要用下列任一方式：

- **本機**：在這個資料夾開啟終端機，執行 `python -m http.server 8123`，再用瀏覽器開 `http://localhost:8123`。
- **放到網路上**：把整個資料夾放到 GitHub Pages 或任何靜態網站空間即可。

## 怎麼玩

1. 在設定畫面選**題庫**、**牌數**（4×4、6×6，或自選組數）與**玩家人數**。
2. 多人時可以輸入每個人的名字；「配對成功可再翻一次」預設開啟，可以取消。
3. 點牌翻開，每翻兩張算一步。配對成功的牌會留在桌上，失敗的會蓋回去。
4. 多人輪流時，畫面會標示輪到誰與各人配對數；結束時顯示排名，同分並列。
5. 單人局會記錄「題庫＋牌數」的最少步數與最短時間，破紀錄時結果視窗會提示。

**牌背**：設定畫面可選蓋起來時顯示「？」或「編號」（1、2、3…，依牌的位置）。編號比較不會讓年紀小的學生有失敗感，老師也能直接喊「請翻 5 號」。

**記憶時間**：設定畫面可選 3、5、10 秒。開局時所有牌先全部亮出並倒數，時間到（或按「開始！」）才蓋牌，計時從第一次翻牌才開始。記憶模式的最佳紀錄與一般模式分開計算。

遊戲進行中按「回設定」會先確認，避免不小心離開。右上角可以隨時開關音效。

## 做自己的題庫

設定畫面按「題庫管理」。

- **新增題庫**：每一組配對有兩張牌，各自可以選「文字」或「圖片」，所以圖配圖、圖配字、字配字都可以，同一個題庫也能混用。
- **圖片**：支援 PNG、JPG、GIF、WebP；不接受 SVG。上傳後會自動縮到最長邊約 600 像素再儲存（GIF 動畫只保留第一格）。
- **內建題庫**不能修改；想改的話按「複製」，再編輯副本。
- **分享題庫**：按「匯出」會下載一個 `.json` 檔，把檔案傳給別人，對方在「題庫管理」按「匯入」即可。匯入前會完整檢查，檔案有任何問題就整個拒絕，不會匯入一半。

**多個題目共用同一個答案**：各建一組配對，答案填一樣的就行。例如「3+4 ↔ 7」和「5+2 ↔ 7」，桌上會有兩張「7」；「3+4」翻到任何一張「7」都算配對成功，兩張牌面一樣的答案牌可以互換。文字會忽略頭尾空白；圖片要是同一張圖（用同一個檔案上傳）才算一樣。

玩 4×4 的題庫至少要有 8 組配對，6×6 至少要有 18 組；題庫的組數比這局需要的多時，每局會隨機抽選。

## 資料存在哪裡

| 內容 | 位置 |
| :--- | :--- |
| 題庫與圖片 | 瀏覽器的 IndexedDB |
| 設定、最佳紀錄 | 瀏覽器的 localStorage |

- 資料只在**同一個瀏覽器、同一個網址**下看得到；換電腦或換瀏覽器不會跟過去，請用匯出／匯入搬移。
- 清除瀏覽器的網站資料會一併清掉題庫與紀錄，重要的題庫請先匯出備份。
- 無痕模式或封鎖網站資料時，無法儲存題庫，只能玩內建題庫；遊戲本身仍可使用。

## 單機版

```
node scripts/build-standalone.js
```

會產生 `dist/翻牌配對.html`：CSS、所有程式、網頁圖示都內嵌在同一個檔案裡，雙擊即可用瀏覽器開啟，也可以放隨身碟或寄給別人。腳本只用 Node 內建模組，不需要安裝任何套件。

- 改過程式後要重新執行一次才會更新；`dist/` 不放進版本控制。
- 以 `file://` 開啟時，題庫與紀錄存在瀏覽器裡「這個檔案」的名下：**換一個資料夾或換檔名，可能會看不到原本的題庫**。搬移題庫請用匯出／匯入。
- 部分瀏覽器（例如 Safari、Firefox 的某些設定）在 `file://` 下不允許儲存資料，此時只能玩內建題庫，遊戲本身仍可使用。建議用 Chrome 或 Edge。
- 想要真正的桌面程式（.exe／.app）需要另外用 Electron 或 Tauri 包裝，這會引入第三方工具，目前沒有做。這個單一 HTML 檔就是要包進去的內容，不需要改程式。

## 平板與觸控

按鈕與牌都做得很大，滑鼠與觸控都能操作，直放橫放都會自動調整牌桌大小。橫放的矮螢幕上，步數、計時與玩家資訊會移到左側，讓牌桌盡量大。

## 開發

- 原生 HTML／CSS／JavaScript（ES module），無建置工具、無第三方套件。
- 測試：`node --test`
- 單機版：`node scripts/build-standalone.js`（合併時會檢查不支援的 import 寫法與頂層名稱衝突，所以不同檔案的頂層名稱不能重複）
- 目錄：
  - `src/game/`：純函式的遊戲規則（洗牌、抽組、翻牌、配對、輪流、排名、紀錄），不碰 DOM 與儲存。
  - `src/store/`：題庫、圖片格式判斷、匯出入、設定與紀錄的儲存。
  - `src/ui/`：畫面、牌桌、音效（Web Audio 合成，沒有音檔）。
  - `src/data/`：內建範例題庫。
  - `scripts/`：單機版打包腳本。
  - `docs/需求.md`：需求與決策。

## 已知限制

- 內建範例題庫的「圖」是 emoji 文字，真正的圖片請自己上傳。
- 沒有桌面程式（.exe／.app）；單機版是單一 HTML 檔。
